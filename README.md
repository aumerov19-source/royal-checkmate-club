# Royal Checkmate Club

Create a beautiful, premium-quality online chess game called Royal Chess. Make it mobile-first and fully responsive for Android phones and desktop browsers.



DESIGN:



- Elegant dark navy and gold theme.

- Beautiful 8x8 chessboard with high-quality chess piece icons.

- Smooth piece movement animations and legal-move highlights.

- Modern home screen with Play Online, Play vs Computer, Friends, Profile and Settings.

- Player avatars, ratings, timers, captured pieces and move history.

- Sound effects, light/dark board themes and polished menus.



CHESS RULES:



- Implement all standard chess rules correctly, including castling, en passant, pawn promotion, check, checkmate, stalemate, and draws.

- Prevent illegal moves.

- Include undo for offline games and a restart button.



ONLINE MULTIPLAYER:



- Allow two real players to play online.

- Create and join games using invite links or room codes.

- Synchronize moves in real time.

- Show whose turn it is and whether a player is online.

- Handle disconnections and reconnecting safely.

- Never pretend online multiplayer works unless the backend is connected and tested.



COMPUTER:



- Add a playable computer opponent with selectable difficulty.



TECHNICAL:



- Use a reliable chess rules library.

- Use Supabase for authentication, game rooms and real-time multiplayer.

- Add secure database access rules.

- Make the app fast and accessible on mobile.

- Provide a working playable prototype, not just a static design.

- Test the chess rules, online moves and mobile layout.



Start by building the chessboard and working local chess gameplay. Then connect and test online multiplayer. Explain any setup steps I need to complete.
